# Crud Java Web Jakarta EEPrimefaces, JPA, Wildfly

## Descripción del Proyecto

Este proyecto es una aplicación web desarrollada con **Java 11** y el stack de **Jakarta EE 10**, implementando un CRUD básico de usuarios.

### Tecnologías y versiones utilizadas

- **Java:** 11  
- **Jakarta Faces (JSF):** 4.0.1  
- **Jakarta EJB:** 4.0.1  
- **Jakarta JPA:** 3.0.0  
- **PrimeFaces:** 14.0.12  
- **PrimeFlex:** 3.3.1  
- **Lombok:** 1.18.34  
- **Hibernate:** 6.6.1.Final  
- **PostgreSQL:** (configurado como proveedor de base de datos)  
- **WildFly Maven Plugin:** para empaquetado y despliegue  
- **Maven:** como sistema de gestión de dependencias y construcción  

La interfaz gráfica está construida con **JSF** y enriquecida con **PrimeFaces**, mientras que la lógica de negocio se gestiona con **EJBs** y la persistencia con **JPA/Hibernate**. Se utiliza **Lombok** para reducir código repetitivo, y todo se empaqueta como un archivo `.war` desplegable en servidores compatibles como **WildFly**.
