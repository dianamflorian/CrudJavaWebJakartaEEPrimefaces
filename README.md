# CrudJavaWebJakartaEEPrimefaces

Este proyecto es una aplicación web desarrollada con Jakarta EE 10, utilizando JSF 4.0 como framework de presentación y PrimeFaces para componentes UI. Implementa un CRUD funcional sobre la entidad <strong>Usuario</strong>, siguiendo el patrón MVC y una arquitectura en capas. La estructura del proyecto incluye capas de presentación, servicios, repositorios y entidades. Está desplegado en un servidor de aplicaciones compatible con Jakarta, como Payara o WildFly, y gestionado con Maven como sistema de construcción.
